# Quote Tool (Desktop)

One-click desktop app for the Prototype Order Calculator.

- Auto-updates via GitHub Releases
- Local PDF export (named after project)
- Import vendor catalog (CSV/TSV/XLS/XLSX/ODS/JSON)
- Saves quotes locally

## Build (CI)
Pushing a tag like `v0.1.0` triggers GitHub Actions to build:
- Windows installer: `QuoteTool-Setup-<version>.exe`
- macOS DMG: `<version>.dmg`
